# FAQ

**Why can't I send my first message?**
Choose a project, or **No project (general)**, in the picker under the message box.

**The project list says it's unavailable.**
Choose **No project (general)** and carry on. The list returns shortly.

**I can't see an agent a colleague shared.**
Ask them to check the share settings and add you or your group. Agents shared with everyone are
in the [Marketplace](agents/marketplace.md).

**An MCP server says "Needs Auth".**
Open the MCP menu, click the server and sign in.

**Revit, SketchUp or Rhino tools don't respond.**
Make sure the application and the Parkhill desktop connector are both open on your workstation.

**The agent stopped in the middle of a long task.**
It reached its step limit. Click continue, or ask the agent owner to raise **Max Agent Steps**.

**I changed an agent and it got worse.**
Open **Version History** in the Agent Builder and **Restore** the earlier version.

**Who do I contact for help?**
The agent's **Support Contact** for agent-specific questions; the AI team for everything else.
