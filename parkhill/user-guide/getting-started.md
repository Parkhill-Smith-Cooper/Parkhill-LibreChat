# Getting started

## Signing in

Sign in with your Parkhill Microsoft account. You don't need a separate password.

---

## Starting a chat

1. Click **New chat**.
2. Pick a model, or an agent, from the selector at the top. For most work an agent is the better
   choice. See [Why agents](agents/README.md).
3. **Choose a project** in the picker under the message box. Search by project number or name,
   or pick **No project (general)** when the chat isn't about a project. Send stays disabled
   until you choose.
4. Type your message and send it.

Choosing a project also files the chat into that project's folder. See [Projects](projects.md).

---

## Shortcuts in the message box

Type one of these characters at the start of the message box:

| Type | What it does |
|---|---|
| `@` | Switch to an agent or model by name. |
| `$` | Run a [skill](skills.md) on this message. |
| `/` | Insert a saved prompt. |
| `+` | Add a second model or agent to the same chat to compare answers side by side. |

---

## Attaching files

Drag files into the message box, or use the attach button. You can ask about PDFs, Word
documents, spreadsheets and images. To give an agent files it should always have, attach them to
the agent instead. See [Create an agent](agents/create.md#knowledge-files).

---

## Tools in the message box

The buttons under the message box turn tools on for the current chat. They include web search,
running code, artifacts (live documents, diagrams and small apps) and **MCP servers**. See
[Tools and MCP servers](mcp.md).
