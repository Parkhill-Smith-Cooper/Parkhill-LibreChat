# Projects

Parkhill AI files your chats by Parkhill project automatically.

---

## Choosing a project for each chat

Before the first message of every new chat, the picker under the message box asks for a
project:

- Search by **project number or name** and select it, or
- choose **No project (general)** for anything not tied to a project.

The choice is made once, on the first message, and stays with the chat.

---

## The Projects section

Choosing a project also files the chat into a folder for it in the **Projects** section of the
sidebar. The folder is named `<number> · <name>`.

- The folder is created the first time you choose that project, and every later chat for that
  project goes into it.
- You can rename the folder; chats still go to it.
- If you delete the folder, it is created again the next time you choose that project.
- **New chat** inside a project folder opens with that project already chosen.
- **No project (general)** chats are not filed anywhere.

You can also create your own folders with **Create project** to group chats any way you like,
for example "Proposal drafts". Chats you start in your own folder stay there.

---

## Why it matters

- You can find every conversation about a project in one place.
- It helps the AI team see which projects benefit from Parkhill AI and where to build agents next.
