# Tips and best practices

## Getting better answers

- **Give context up front:** the project, the audience and what "done" looks like.
- **Attach the source** instead of describing it. The assistant reads the actual document.
- **Ask for a format:** a table, a checklist, an email draft or "three options with pros and
  cons".
- **Correct it in the same chat.** "Shorter, and drop the second paragraph" works better than
  starting over.
- **Check facts that matter.** Verify code sections, quantities, dates and names before they
  leave the building.

---

## Getting the most from agents

- **Use an agent before a blank chat.** Check the [Marketplace](agents/marketplace.md) first.
- **Turn repeated prompts into agents.** If you paste the same setup text twice, build an
  agent.
- **Keep agents narrow.** Several focused agents beat one that tries to do everything.
- **Maintain what you share.** Keep knowledge files current and update instructions when
  people report weak answers.
- **Use skills for shared "how-to".** Formatting rules, checklists and templates belong in a
  [skill](skills.md) that many agents can use.

---

## Safety

- Follow our data policies: don't paste passwords, personal financial data or anything a client
  contract forbids.
- MCP tools act with **your** permissions. Read what the assistant proposes before asking it to
  send, change or delete anything.
