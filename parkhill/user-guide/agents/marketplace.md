# Find agents in the Marketplace

The **Agent Marketplace** lists every agent shared with everyone, plus agents shared with you.
Check it before building something new.

---

## Browsing

- **Top Picks** are agents the AI team recommends.
- **Category tabs** (General, IT, R&D, Sales and others) group agents by area.
- **Search** matches agent names and descriptions. Search for the task ("RFI", "spec",
  "schedule"), not just the discipline.

Click an agent card to see its description, who built it and its support contact. Click
**Start Chat** to use it.

---

## Using an agent you found

- In any chat, type `@` and the agent's name to switch to it.
- If an agent is close but not quite right, **Duplicate** it (if you have permission) and adjust
  your copy. Tell the owner what you changed, since it may help them too.
- If it gives a wrong or weak answer, send the example to its support contact. Agents get better
  from feedback.

---

## Getting your agent listed

[Share it with everyone](share.md), pick a **category** and write a clear **description**. To
have it considered for **Top Picks**, contact the AI team.
