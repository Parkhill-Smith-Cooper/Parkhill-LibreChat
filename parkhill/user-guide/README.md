# Parkhill AI user guide

Parkhill AI is our company chat assistant. You can use it like any AI chat, but it does its best
work through **agents**: assistants set up once for a specific job and then shared with the
people who need them.

This guide shows you how to:

- **[Get started](getting-started.md):** start a chat, choose a project and use the shortcuts in
  the message box.
- **[Create agents](agents/create.md)** that are experts in one thing, and
  **[share them](agents/share.md)** with your team.
- **[Find agents](agents/marketplace.md)** that colleagues have already built in the
  Agent Marketplace.
- **[Keep chats organized](projects.md)** by Parkhill project.
- **[Connect tools](mcp.md)** such as Microsoft 365, RED, Pirros, Revit, SketchUp and Rhino.
- **[Use skills](skills.md)**, which are reusable instruction packs for agents.

---

## The one idea to take away

> Don't re-explain the same task in every chat. Build an agent for it once, then share it.

A generic chat starts from zero each time. An agent already knows its role, your standards, the
right tools and the reference files. Each improvement you make to an agent helps everyone who
uses it.
